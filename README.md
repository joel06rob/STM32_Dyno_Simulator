# STM32_Dyno_Simulator

### (In Development)

An embedded automotive dynamometer simulation project using an STM32F446RE microcontroller and Arduino Uno Q as interconnected Engine and Dyno ECUs. The system simulates engine parameters (RPM, throttle position and temperature), calculates dynamometer performance metrics (torque, BHP) and communicates data over a Classic CAN bus, with data then being displayed on a custom Qt desktop dashboard for real-time monitoring and visualisation.

## Technologies Used

- **Microcontrollers:** STM32F446RE Nucleo, Arduino Uno Q
- **Other Components:** Potentiometer, SN65HVD230, OLED Display...
- **Communication Protocols:** CAN, UART, I2C
- **Programming Languages:** C, C++, Qt
